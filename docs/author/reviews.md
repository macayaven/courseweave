# Author reviews and course coverage

The v0.3.0 candidate keeps model findings, quotation provenance and your decisions
separate. A located quotation matches the selected source snapshot; it does not
establish that the source or model judgment is true. These private reviews do not
change student progress or certify mastery.

## Request and save a review

1. Save the course and selected content. Review source decisions in **Sources**.
   In **Author assistant**, select the activity or file, choose a role, and
   explicitly permit approved references. Inspect the saved context and omissions.
   To connect a file review to an activity's objectives, select that activity and
   check **Associate file review with selected activity**. The server checks that
   the file belongs to the activity.
2. Use **Fact checker** for evidence-linked claims, **Proofreader** for wording and
   coherence, or **Compatibility reviewer** to explain supplied canonical findings.
   All six roles use the same bounded, saved selection and permission boundary.
   Ask for one small review. A malformed, incomplete, stale or invalidly cited
   response is rejected without an automatic repair request. Inspect the failure
   and manually revise the request if useful.
3. Inspect each finding and its exact quotation. **Save review report** deliberately
   stores the validated summary and findings, initially **Unreviewed**. Conversation
   remains session-only. If a reply also proposes an edit, **Save draft for review**
   is a separate action. Applying that draft still requires its exact diff review.
4. In **Saved review reports**, choose a finding and record your disposition.
   **Dismissed** and **Revised** require a reason; **Accepted** records your decision
   without rewriting the model's judgment. A revised disposition alone does not
   edit the lesson. Save each finding before moving to another.
5. Select objective links deliberately. **Inspect coverage** shows saved activity
   prompts, objectives, authored hints/checks, declared references and review gaps.
   Completion prompts and declared sources apply to their activity. An objective
   gets an author-accepted evidence link only from an explicitly mapped, current,
   located, supported finding with an accepted or revised disposition.

Coverage reports required, optional and excluded activities using canonical course
metadata. Courses without objectives remain supported; missing guidance is shown
without inventing objectives, inferring file associations or changing requirements.
Unreviewed, unsupported or stale findings remain visible gaps unless dismissed.
A source declaration alone is not a reviewed evidence link.

## Reopen, revise and export

Saved reports survive app restart independently of the model session. They retain
the selected scope, source attribution and dates, snapshot hashes, prompt version,
context budget and omissions, and the actual bounded compatibility diagnostics
supplied to that request. Unknown dates remain unknown. Local provenance uses the
source filename rather than exporting the original absolute machine path.

On read, the service checks current project, manifest, target and source revisions,
raw and extracted hashes, approval, provenance metadata and quotation spans.
Changes make dependent reports **Stale** while retaining their original judgment
and your decision. A stale report cannot acquire an accepted/revised decision;
request a fresh review of the current selection. Dismissal with a reason remains
available. Compatibility diagnostics cover saved-course structure, local assets
and the frozen Student profile, with unperformed checks disclosed. The model cannot
set or override a compatibility pass flag.

Concurrent changes reject a stale decision revision and preserve your unsaved note.
Use **Discard decision edits**, then **Reload reviews** when ready to inspect the latest report.
**Export review JSON** downloads the explicitly selected report revision, including
private review text; inspect it before sharing. **Delete report** requires the
displayed confirmation and revision. Export first if you want a retained copy.
Deletion cannot be undone by reusing the old session's Save button.

Reports are limited to 200 per project and 512 KiB each, with lists and coverage
paged twenty at a time. The service never silently prunes old evidence. Explicitly
export/delete selected reports or archive the project when reaching the limit.
Source excerpts and assistant context have the smaller bounds documented in
[research](research.md). Corrupt artifacts remain visible errors; they are not
silently regenerated by the model.

These are candidate features. Development tests and inspected model examples do
not replace the required fresh installation, real discovery, paired Student
journeys or independent release review in the [implementation notes](implementation.md).
