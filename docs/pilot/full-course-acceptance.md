## Independent review and focused fixes

A bounded independent source review initially found two P2 defects. The full-suite command defaulted to the reference implementation, so S13 could measure the wrong core. S13 audit instructions and S14 regression commands now explicitly use `--impl student`, require `impl=student` in the report and inspection of failures/skips, and keep regression fixtures separate from unseen acceptance/holdout. The regression invoked the actual runner selection path: the former command selected reference; the corrected command selects student.

Browser verification also exposed bare native module links that did not match the declared reading fragments, and unlisted Index/study-plan references. Generated links now use canonical fragments. Four explicit optional S01 orientation references preserve navigation without adding a fake module or widening file access. The exhaustive generated-anchor regression covers all sixteen pages. S09/S10 also lacked notebook kernel metadata; only that metadata was added, preserving every exercise cell and output-free source.

Async terminal creation could return focus to an earlier activity after the next lesson was selected. Navigation now finishes in request order. Independent review caught a repeated A → B → A selection suppressed by an old broker deduplication rule; that redundant rule was removed. Both regressions passed from the built library and the original rapid sequence passed from the exact delivered package.

Independent review also reproduced an early-click window: a native link could become visible before a diagram finished loading, and its default browser navigation changed the reader without updating the assistant activity. Explicit reader navigation now creates a fresh inert iframe and binds its local links before enabling interaction. A superseded iframe load cannot unlock or scroll a newer one. Read/self-check fragment transitions remain usable; an explicit activity open reloads that static document, while revisiting its tab preserves it. The initial package probe used a wrapped-anchor bounding-box center that could miss the link. Independent review detected that test gap; the corrected probe clicks an actual rendered anchor line. The corrected old-package receipt explicitly records S02 visible while the last confirmed activity remains S01. The corrected f113 receipt holds S01 during loading and then opens S02 with matching context. These receipts are `reader-load-anchor-before/student-acceptance.json` and `reader-load-anchor-final/student-acceptance.json`; the final all-course run repeats the same helper.

All reading surfaces formerly shared generic labels, concealing a retained earlier lesson excerpt after navigation. All HTML/Markdown labels now identify their session and are unique, including the new orientation references. The README explains that navigation retains the explicit excerpt until the learner chooses **Use this lesson** or **Clear lesson scope**. Both fixes passed focused red/green checks and independent source reinspection. No unresolved source finding remained in that bounded pass.

A live mechanism question exposed an inconsistency in S11: its notebook and guided feedback already allowed estimate undershoot, while the lesson implied a strict ceiling. The corrected lesson distinguishes predicted refusal, actual accounting and conservative or verified hard enforcement. Independent review also checked the linked official LiteLLM example, which permits a first-call overshoot and blocks later calls; the lesson and reading-table entry now state that limit. The exact final two-file source/HTML diff was independently approved before commit. All notebooks and the manifest are byte-identical to the preceding fully exercised course.
